# Dayline Calendar

An iOS-first React Native calendar prototype built with Expo SDK 54. It demonstrates calendar layout, interaction design, and production-minded mobile UX.

## Run locally

```bash
npm install
npm run ios
```

Alternatively, run `npm start` and choose a supported platform from the Expo development server.

## Prototype features

- Scrollable day timeline with a live current-time marker
- Automatic layout for overlapping events
- Horizontal day swipes and direct date selection
- Event completion and empty-day states
- Native-style event detail sheet and haptic feedback

## Stack

- React Native 0.81
- Expo SDK 54 and Expo Router
- TypeScript
- React Native Animated and PanResponder
